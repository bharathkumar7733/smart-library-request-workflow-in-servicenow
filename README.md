# 📚 Smart Library Request Workflow in ServiceNow

An automated end-to-end enterprise solution built on the **ServiceNow Platform** to streamline university library book catalog browsing, request submissions, managerial approvals, and inventory management.

## 🚀 Key Modules & Phase Breakdown

### 📋 Project Lifecycle Documentation
This repository includes complete phase documentation covering:

- **Ideation & Design Templates**: System architecture, table schemas, and workflow flowcharts.

---

## 🛠️ ServiceNow Core Concepts Implemented
- **Service Catalog & Request Items (RITM)**: Custom portal forms for book borrowing and returns.
- **Flow Designer Automation**: Automated multi-stage approval routing to librarians.
- **Access Control Lists (ACLs)**: Role-based security for student vs. admin views.
- **UI Policies & Data Policies**: Dynamic field validation and required field governance.
- **Reports & Dashboard**: Visual reporting on top requested books and inventory availability.
